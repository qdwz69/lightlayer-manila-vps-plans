## Premium 和 Global 差在哪，该选哪条

这个差别对两类人意义完全不同。

如果你的访客、店铺后台操作、API 调用主要从中国大陆发起，Premium 值这同样的 $24.99。如果你的用户本身就在菲律宾或东南亚，或者这台机器只用来对接第三方平台、不关心回国路由，Global 更合适：同价位下它的带宽给到 10Mbps 不限流量，或者 20Mbps 带 1TB 月流量，比 Premium 的 5Mbps / 10Mbps 宽一档。

在“不限流量”和“1TB 月流量”之间挑，看的是流量形态而不是总量大小。博客、企业站、API、监控探针这类长期低速率、但在线的服务，选不限流量版，5Mbps 或 10Mbps 的管道够用而且不用担心月底被限速。有阶段性高峰的（批量上传、镜像同步、短视频素材分发），选 1TB 版，用峰值带宽换总量上限。1TB/月对一台 1GB 内存的机器来说不算小，真正会跑满的是代理和下载类业务。

## IP 是不是本地原生，怎么自己验

原生 IP 的通行定义是：IP 地址所属运营商的国家与服务器所在国家一致。住宅 IP 则是 ISP 分配给家庭用户的地址，来自真实家庭网络，在某些平台的判定里更接近“真人用户”。

LightLayer 的马尼拉产品资料里没有明确写“原生 IP”这个标注。同一品牌洛杉矶机房被标为原生 IP，香港、台湾、新加坡被标为非原生，马尼拉不在这个明确列表里。这一点值得在下单前用两种方式确认：一是看订购页的产品描述里有没有写明 IP 属性；二是开通后用 IP 查询工具看 ASN 归属，登记运营商是菲律宾本地 ISP，还是机房持有的广播地址段。两种结果对 GEO 定向、广告账户环境、支付网关风控的影响不一样。

顺便说一个被过度营销的点。市面上流行的“IP 欺诈值”“纯净度评分”并没有统一评分依据，IP 也没有绝对意义上的“干净”“新老”之分，TikTok 这类平台自己维护 IP 库和检测手段，第三方打分只能当参考。这是某家服务商官方 FAQ 里的说法，不是行业定论，但它提醒的事情是对的：别为一个查不到出处的评分多付钱。

## 退款、试用、换 IP：付款前要问的三件事

LightLayer 的价格页和活动公告里没有出现明确的退款期限或“随时销毁退款”承诺，这一点跟一些按月计费、支持按小时试用的商家不一样。付款前建议在订购页或开工单确认两个问题：年付产品有没有退款窗口、开通后不满意能不能退。

行业里常见的做法可以拿来对照。朝暮数据的多数可用区支持随时销毁退款或按小时付费，用来做短期试用；但它也把 C、Z、LH、P 几个可用区明确标成“不支持退款”，这些区只能靠测试 IP 测延迟和路由。也就是说，即使在同一家服务商内部，能不能退也是按可用区分的，不能想当然。

换 IP 也有坑。通过销毁重开换 IP 是常见手段，但刚释放的地址有可能被重新分配回来，稳妥顺序是先订购新机器再销毁旧的，或者销毁后隔几小时再下单。另外，并不是每个机房、每个可用区都支持更换主 IP 或增加 IP，下单前确认清楚。

## 马尼拉“近”不等于“快”

从大陆访问马尼拉，物理距离确实比美西近，但实际速度取决于国际出口带宽、出境路由和运营商互联。国际链路拥塞时段，马尼拉和洛杉矶的体感差距可能没有地图上那么大。

这也是 Premium 线路存在的理由。CN2 + 大陆 BGP 的组合就是为了绕开普通国际路由的拥堵点，代价是同样的钱只能买到 5–10Mbps 带宽。如果这台机器的主要使用者在大陆，这条溢价是值的；如果只是给菲律宾本地用户提供服务，Global 线路加更大带宽更实在。

下单前如果有测试 IP，先 ping 一遍、再看一眼路由跳转，比看任何评测都准。开通后发现线路不合适的换线成本，比付款前多花十分钟高得多。
